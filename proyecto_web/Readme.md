# Proyecto Django Blog

## Descripción
Proyecto realizado con Django utilizando el patrón MVT.

## Funcionalidades
- Panel admin para gestionar datos
- Modelos: Autor, Post, Comentario
- Página principal con herencia de templates

## Cómo probar

1. Ejecutar:
python manage.py runserver

2. Ir a:
http://127.0.0.1:8000/

3. Admin:
http://127.0.0.1:8000/admin/
