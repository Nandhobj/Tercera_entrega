Bienvenido/a

Este sitio es un proyecto en Django que combina un blog, páginas tipo “artículo” y mensajería entre usuarios. Desde la barra de navegación podés recorrer todas las secciones.

Sobre el proyecto

Está construido con el patrón MVT (Modelo - Vista - Template), incluye autenticación (registro, login/logout), perfil editable con avatar, un módulo de Pages con editor de texto enriquecido, y un sistema de mensajes para comunicarte con otros usuarios.

Secciones disponibles

  • About: conocé al dueño/a del sitio.
  • Pages: listado de páginas con “Leer más” para ver el detalle.
  • Blog: publicaciones (posts) con listado, detalle y buscador.
  • Profile: tus datos, avatar y cambio de contraseña.
  • Messages: inbox, enviados y redacción de mensajes.
